# Delicias los Lagos

Sitio estático de presentación para la pastelería. Incluye el catálogo, información del negocio y enlaces de contacto.

## Publicación

Sube `index.html`, `favicon.svg`, `assets/`, `robots.txt` y `sitemap.xml` a cualquier hosting de archivos estáticos. No requiere PHP, base de datos, instalación ni compilación.

## Edición

- Cambia textos, precios y enlaces de contacto directamente en `index.html`.
- Actualiza los estilos en `assets/css/style.css`.
- Reemplaza las imágenes dentro de `assets/img/`.

El sitio no incluye formularios, cuentas, panel administrativo, almacenamiento local ni envío de datos a un servidor. Los enlaces de contacto abren WhatsApp o el programa de correo del visitante.
